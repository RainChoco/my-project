# Test Cases - Calista (Backend)

## boardPaperScopeC.test.js

| Test ID | Test Name | Description | Expected Outcome |
|---|---|---|---|
| BE-CT-001 | Rejects an unauthenticated board paper generation request | Calls `POST /api/board-papers/generate` with a valid payload but no Authorization header. | Response status code is 401. |
| BE-CT-002 | Rejects a board paper request from a disallowed role | Calls `POST /api/board-papers/generate` using a token for an `evaluator` role, which is outside report_preparer/management/ma_staff. | Response status code is 403. |
| BE-CT-003 | Rejects an unauthenticated proposal generation request | Calls `POST /api/proposals/generate` with an empty body and no Authorization header. | Response status code is 401. |
| BE-CT-004 | Rejects a proposal request from a disallowed role | Calls `POST /api/proposals/generate` using the `evaluator` token with an empty body. | Response status code is 403. |
| BE-CT-005 | Rejects a board paper list request with an invalid token | Calls `GET /api/board-papers` with an Authorization header containing a bogus token string. | Response status code is 401. |
| BE-CT-006 | Returns 400 when proposal generation has no boardPaperId and no board paper exists | Calls `POST /api/proposals/generate` as `report_preparer` with an empty body before any board paper has been created. | Response status code is 400 with message "Unable to create proposal because no board paper is available." |
| BE-CT-007 | Rejects board paper generation without a tenderId | Calls `POST /api/board-papers/generate` as `report_preparer` with a title and purpose but no `tenderId`. | Response status code is 400 with message "Tender is required." |
| BE-CT-008 | Returns 404 when the referenced tender does not exist | Calls `POST /api/board-papers/generate` as `report_preparer` with a non-existent `tenderId` (999999). | Response status code is 404 with message "Tender not found". |
| BE-CT-009 | Generates a board paper from a real tender with a deterministic AI narrative | Calls `POST /api/board-papers/generate` as `report_preparer` for the eligible seeded tender "TC-CALISTA-001" with title, purpose, and preparedBy (no `OPENAI_API_KEY` set in the test env, so the deterministic fallback narrative is used). | Response status is 201 with message "Board Paper generated successfully."; the returned report has the correct tenderId/title/purpose/status "Generated"/generatedBy "EM Services AI Platform"; `confidence` is an integer between 0-100 and `score` is `"<confidence> / 100"`; `aiSummary` contains the tender ref no, vendor name, and confidence percentage; `aiRiskLevel` is one of Low/Medium/High and is consistent with the confidence bracket (>=75 Low, >=50 Medium, else High); `aiRecommendation` contains the vendor name and `finalRecommendation` equals `aiRecommendation`. |
| BE-CT-010 | ma_staff can also generate a board paper | Calls `POST /api/board-papers/generate` as `ma_staff` for the same eligible tender. | Response status is 201 and the report's purpose is "Information Only"; the created board paper is then deleted to avoid affecting later list-count assertions. |
| BE-CT-011 | management can also generate a board paper | Calls `POST /api/board-papers/generate` as `management` for the same eligible tender. | Response status is 201; the created board paper is then deleted to avoid affecting later list-count assertions. |
| BE-CT-012 | Lists all board papers, most recent first | Calls `GET /api/board-papers` as `ma_staff` after the main board paper has been generated. | Response status is 200, the body is an array, and it includes the previously generated board paper's id. |
| BE-CT-013 | Retrieves a single board paper by id | Calls `GET /api/board-papers/:id` as `report_preparer` for the generated board paper's id. | Response status is 200 and the returned id/title match the generated board paper. |
| BE-CT-014 | Returns 404 for a board paper that does not exist | Calls `GET /api/board-papers/999999` as `report_preparer`. | Response status is 404 with message "Board Paper not found." |

| BE-CT-016 | Returns 404 when updating a board paper that does not exist | Calls `PUT /api/board-papers/999999` as `report_preparer` with a title change. | Response status is 404 with message "Board Paper not found." |
